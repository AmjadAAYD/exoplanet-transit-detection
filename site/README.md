# ExoDetect showcase site

A static Astro site presenting the [exoplanet-transit-detection](https://github.com/AmjadAAYD/exoplanet-transit-detection)
results: the sync animation, validation tables, BLS-vs-classifier comparison, discovery batch summary, and a
curated interactive demo (real, pre-computed light curves and periodograms for 8 targets).

## Structure

- `src/pages/index.astro`: the single page, assembles all sections
- `src/components/`: one component per section (`Hero`, `ValidationSection`, `ClassifierSection`,
  `DiscoverySection`), plus the interactive demo (`Demo.tsx`, `LineChart.tsx`)
- `src/data/validation.json`: the consolidated validation table (mirrors `../docs/validation_table.csv`)
- `public/data/*.json`: per-target demo data, generated by `../notebooks/export_site_data.py`. Curated and
  pre-computed, not a live lookup: see that script's docstring for why.
- `public/images/`: copies of the project's key figures

## Commands

```sh
npm install
npm run dev       # dev server at localhost:4321
npm run build     # static output to dist/
npm run preview   # serve the production build locally, also at localhost:4321
```

## Regenerating the demo data

```sh
cd ..
python notebooks/export_site_data.py
```

Requires the same Python environment as the main pipeline (`pip install -r ../requirements.txt`); reuses cached
light curves from earlier phases where available.
